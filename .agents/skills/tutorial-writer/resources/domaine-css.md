# Domaine CSS & Mise en Page (`domaine-css`)

> **Ressource Didactique — Spartel N1**  
> **Compétence associée :** `tutorial-writer`  
> **Périmètre :** Styles, sélecteurs, modèle de boîte, Flexbox, CSS Grid, Responsive.

---

## 1. Isolation de Préparation
- Le HTML de structure et le CSS décoratif (couleurs d'arrière-plan, bordures d'aide) sont placés dans une balise `<style>` à l'intérieur de `data_html`.
- **Espace de Travail Apprenant Vierge :** Le champ `data_css` reste vierge (ou contient seulement un sélecteur vide avec commentaire d'instruction) afin que l'apprenant écrive son CSS sans être distrait ni pollué.

---

## 2. Progression Didactique N1
Sélecteurs élémentaires (`element`, `.classe`, `#id`) $\rightarrow$ Modèle de boîte (`margin`, `padding`, `border`, `box-sizing`) $\rightarrow$ Typographie & Couleurs $\rightarrow$ Flexbox (axes, alignement, wrap) $\rightarrow$ Grid basique $\rightarrow$ Media Queries & Responsive Design.

---

## 3. Schémas Visuels Obligatoires
Pour tout concept de mise en page (Flexbox axes `row`/`column`, `justify-content`, `align-items`), inclure impérativement un schéma visuel SVG ou Mermaid illustrant les flux d'alignement.
