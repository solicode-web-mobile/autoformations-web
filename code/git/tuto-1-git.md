# Résultat attendu : Configuration de Git

Pour que votre environnement Git soit correctement configuré, vous devez avoir exécuté avec succès les 3 commandes suivantes dans votre terminal :

```bash
# 1. Vérifier que Git est bien installé
git --version

# 2. Configurer son prénom et nom (votre signature)
git config --global user.name "Prénom Nom"

# 3. Configurer son adresse email
git config --global user.email "email@exemple.com"
```
