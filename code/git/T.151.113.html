🤖 Ce que fait VS Code en arrière-plan

$ # 1. Quand vous cliquez sur "Cloner le dépôt" :

git clone https://github.com/utilisateur/mon-projet.git

Cloning into 'mon-projet'... ✓ Récupéré

$ # 2. Quand vous cliquez sur le bouton "+" (Préparer) :

git add index.html

✓ Fichier préparé (Staged)

$ # 3. Quand vous cliquez sur "Valider" (Commit) :

git commit -m "Ajout du titre principal"

[main a1b2c3d] Ajout du titre principal ✓ Historique mis à jour

$ # 4. Quand vous cliquez sur "Synchroniser" :

git push origin main

To https://github.com/utilisateur/mon-projet.git ✓ GitHub est à jour
