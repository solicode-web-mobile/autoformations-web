📖 Résumé : Git vs GitHub

Git (L'outil local)

  • • Quoi : Un outil de gestion de versions.
  • • Où : Installé localement sur votre ordinateur.
  • • Rôle : Enregistrer l'historique du projet.
  • • Internet : ❌ Non requis.

GitHub (Le service en ligne)

  • • Quoi : Une plateforme d'hébergement.
  • • Où : Sur Internet (Cloud).
  • • Rôle : Héberger, partager le dépôt et collaborer.
  • • Internet : ✅ Requis.

Règle d'or : Git n'est pas GitHub. Git est l'outil sur votre machine, tandis que GitHub est un service en ligne qui héberge vos projets Git.
