💡 Exemple interactif

Comment une donnée reçoit une valeur saisie

Le champ du formulaire représente la donnée. Le texte saisi par l'utilisateur devient sa valeur.

📝 Formulaire rempli par l'utilisateur
nom_auteur
prenom_auteur
email_auteur
🔍 Analyse des données saisies
Association Donnée ➔ Valeur
Donnée : nom_auteur ➔ Madani
✏️ Donnée saisie
Donnée : prenom_auteur ➔ Ali
✏️ Donnée saisie
Donnée : email_auteur ➔ madani@mail.com
✏️ Donnée saisie
À retenir : La donnée (ex. nom_auteur) est l'élément prévu par l'application. La valeur (ex. Madani) est fournie par l'utilisateur lors de la saisie.
