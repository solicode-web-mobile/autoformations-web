# Projet Fil Rouge — Intégrer les informations d’un article

## 1. Objectif

Réutiliser les variables, les entrées, les calculs et les sorties dans le **Blog personnel**.

## 2. Contexte

Le Blog personnel contient des articles. Une partie des informations d’un article doit être préparée et affichée avec JavaScript.

## 3. Travail à faire

### Étape 1 — Préparer les données

Créez les variables nécessaires pour représenter un article :

* titre ;
* prix ;
* quantité ;
* remise.

### Étape 2 — Recevoir les données

Demandez avec `prompt()` les informations qui doivent être saisies par l’utilisateur.

### Étape 3 — Calculer les informations

Calculez le sous-total, la remise et le total.

### Étape 4 — Afficher les résultats

Affichez les informations de l’article dans la console.

## 4. Fonctionnalités attendues

* Stocker les informations de l’article.
* Recevoir des valeurs utilisateur.
* Calculer le montant total.
* Afficher les informations et le résultat.

## 5. Résultat attendu

Le programme permet de saisir les informations d’un article du Blog personnel et affiche les résultats calculés.

## 6. Livrable

Le fichier JavaScript intégré au projet du **Blog personnel**.

## 7. Critères de réussite

* Les variables sont correctement utilisées.
* Les entrées sont correctement récupérées.
* Les calculs sont corrects.
* Les résultats sont correctement affichés.
* La fonctionnalité est intégrée au projet.
