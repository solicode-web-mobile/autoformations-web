# Tutoriel — Découvrir les langages du Web

Découvrir **HTML, CSS, JavaScript et PHP** et comprendre le rôle de chacun dans une application Web.

**Prérequis** : Un navigateur Web et une connexion Internet sont nécessaires.

# Partie 1 — Théorie

## 1.1. HTML — Structurer la page

**HTML** permet de créer la **structure et le contenu** d’une page Web.

**Exemple :** créer un titre, un paragraphe ou une image.

## 1.2. CSS — Présenter la page

**CSS** permet de modifier **l’apparence** d’une page Web.

**Exemple :** modifier une couleur, une taille ou la position d’un élément.

## 1.3. JavaScript — Ajouter des actions

**JavaScript** permet d’ajouter des **actions et des comportements** à une page Web.

**Exemple :** afficher un message lorsqu’un bouton est cliqué.

## 1.4. PHP — Traiter les données

**PHP** est un langage exécuté sur le **serveur**.

Il permet de créer des pages dynamiques et de traiter des données.

**Exemple :** enregistrer les données d’un formulaire.

## 1.5. À retenir

* **HTML** → structure et contenu.
* **CSS** → apparence.
* **JavaScript** → actions et comportements.
* **PHP** → traitement côté serveur.

# Partie 2 — Pratique

## 2.1. Observer les langages

### Étape 1 — Ouvrir une page Web

Ouvrez une page Web dans votre navigateur.

Observez son contenu et son apparence.

### Étape 2 — Identifier HTML et CSS

Ouvrez les outils du navigateur.

Observez le code HTML et les règles CSS utilisées par la page.

### Étape 3 — Observer JavaScript

Ouvrez la console du navigateur.

Observez un exemple simple de code JavaScript fourni par le formateur.

### Étape 4 — Observer PHP

Consultez un exemple simple de code PHP fourni par le formateur.

Identifiez ce que PHP peut faire sur le serveur.

**Résultat attendu :**

Vous pouvez identifier le rôle de **HTML, CSS, JavaScript et PHP**.

## 2.2. Créer la présentation

### Étape 5 — Créer une présentation

Créez une présentation avec **Google Slides**.

Utilisez **3 slides maximum**.

Présentez :

* **HTML** : structure ;
* **CSS** : apparence ;
* **JavaScript** : actions ;
* **PHP** : traitement des données.

Ajoutez un exemple simple pour chaque langage.

### Étape 6 — Partager la présentation

Cliquez sur **Partager**.

Sélectionnez :

**Toute personne disposant du lien**

Choisissez **Lecteur**.

Cliquez sur **Copier le lien**.

### Étape 7 — Présenter

Partagez le lien avec les autres apprenants.

Présentez votre travail devant le groupe.

**Résultat attendu :**

Les autres apprenants peuvent consulter votre présentation et vous pouvez expliquer simplement le rôle des quatre langages.

# 3. Bilan

**Vous avez réalisé :** une présentation sur HTML, CSS, JavaScript et PHP.

**Vous savez maintenant :** expliquer simplement le rôle de ces quatre technologies dans une application Web.

# 4. Glossaire

* **HTML** : langage qui structure le contenu d’une page Web.
* **CSS** : langage qui définit l’apparence d’une page Web.
* **JavaScript** : langage qui ajoute des actions à une page Web.
* **PHP** : langage exécuté sur le serveur pour traiter des données et produire des pages dynamiques.
* **Serveur** : ordinateur qui fournit des données ou des services à d’autres ordinateurs.
