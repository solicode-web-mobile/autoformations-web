# S1 — Découvrir le Projet et Formation

**Sous-titre :** Découvrir le fonctionnement d’une application Web, comprendre le projet cible, identifier son contexte et ses acteurs et construire les premiers traitements JavaScript dans le Sandbox Algorithmique.

**Description :** L’apprenant découvre le cadre général du parcours et le fonctionnement d’une application Web avant de commencer sa réalisation. Il observe la maquette du Blog personnel afin d’identifier sa finalité générale, son contexte fonctionnel, son périmètre et ses principaux acteurs. Il découvre également le rôle des données dans une application et identifie les premières données nécessaires à son fonctionnement. En parallèle, il construit les premiers traitements JavaScript dans le **Sandbox Algorithmique** en utilisant des variables, des valeurs, des entrées et des sorties. Il découvre enfin les principaux outils utilisés pendant la formation à travers des Labs. Aucune page Web n’est construite dans ce Sprint.

## Étape de réalisation

**Titre :** Comprendre le projet et construire les premiers traitements logiques

**Description :** Découvrir le projet cible, analyser son contexte et ses acteurs, comprendre le rôle des données dans l’application et construire un premier traitement JavaScript simple dans le Sandbox Algorithmique.

**Livrable :**

* Analyse du contexte et des acteurs du Blog personnel.
* Liste initiale des données nécessaires au fonctionnement de l’application.
* Programmes JavaScript simples exécutés dans le Sandbox Algorithmique.
* Productions des Labs de découverte.

**Sandbox Algorithmique :** Présent.

## Sandbox Algorithmique

**Objectif :** Construire des traitements JavaScript simples permettant de stocker des valeurs, recevoir des données simples, effectuer un calcul et produire un résultat observable.

### UA.121.11 — Manipuler les variables et les entrées-sorties

* **Compétence :** C.1.2.1 — Construire le traitement logique
* **Micro-compétence :** D.121.1 — Construire et programmer des traitements logiques
* **Objectif d’apprentissage :** Construire un traitement JavaScript simple permettant de stocker des valeurs, recevoir des données et produire un résultat observable.
* **Contexte :** Sandbox Algorithmique.
* **Travail à faire :**

  * Déclarer des variables contenant des informations simples sur un article.
  * Affecter des valeurs aux variables.
  * Afficher les valeurs dans la console.
  * Recevoir des valeurs simples.
  * Effectuer un calcul élémentaire sur les valeurs reçues.
  * Afficher le résultat obtenu.
* **Livrable UA :** Petit programme JavaScript exécuté en console manipulant plusieurs valeurs, réalisant un calcul simple et affichant un résultat.
* **Preuve attendue :** Programme exécutable produisant correctement les résultats attendus avec différentes valeurs.

**Résultat du Sandbox :** L’apprenant est capable de déclarer des variables, stocker des valeurs, recevoir des données simples, effectuer un traitement élémentaire et afficher le résultat dans la console.

## Mobilisation des unités d’apprentissage

### UA.111.11 — Identifier le contexte et les acteurs

* **Compétence :** C.1.1.1 — Analyser un besoin existant
* **Micro-compétence :** D.111.1 — Identifier les actions des acteurs
* **Objectif d’apprentissage :** Analyser un support fonctionnel fourni afin d’identifier la finalité générale de l’application, son domaine fonctionnel, son périmètre et les différents acteurs concernés.
* **Contexte :** Blog personnel.
* **Travail à faire :** À partir des maquettes du Blog personnel, identifier l’application, sa finalité, son contexte fonctionnel, son périmètre et les acteurs **Administrateur** et **Visiteur** ainsi que leurs rôles.
* **Livrable UA :** Analyse du contexte et des acteurs comprenant **Application → Finalité → Acteurs → Rôles**.
* **Preuve attendue :** Analyse permettant d’identifier clairement ce qu’est l’application, pourquoi elle existe, dans quel périmètre elle s’inscrit et quels acteurs interviennent dans le système.

### UA.112.11 — Comprendre le rôle des données dans une application

* **Compétence :** C.1.1.2 — Modéliser les données
* **Micro-compétence :** D.112.1 — Comprendre le rôle des données dans une application
* **Objectif d’apprentissage :** Comprendre pourquoi une application informatique a besoin de données structurées et identifier les principales données nécessaires à son fonctionnement.
* **Contexte :** Blog personnel.
* **Travail à faire :** À partir des fonctionnalités observées dans le Blog personnel, identifier les principales données nécessaires à leur fonctionnement et distinguer les données manipulées par l’application.
* **Livrable UA :** Liste initiale des données nécessaires au fonctionnement de l’application associée aux principales fonctionnalités observées.
* **Preuve attendue :** Données pertinentes identifiées et reliées aux fonctionnalités correspondantes.

## Labs de découverte

**Objectif :** Comprendre les principaux éléments qui interviennent dans la réalisation et l’utilisation d’une application Web.

### Lab 1 — Comprendre un site et une application Web

**Travail à faire :**

* Observer une application Web existante.
* Identifier ce qu’est un site Web.
* Identifier ce qu’est une application Web.
* Observer les éléments visibles dans un navigateur.
* Relier les éléments observés au Blog personnel.

**Livrable :**

* Fiche de découverte **« Site Web / Application Web »**.

### Lab 2 — Découvrir HTML

**Travail à faire :**

* Observer une page HTML simple.
* Identifier le rôle de HTML.
* Repérer quelques éléments HTML.
* Relier la structure HTML au contenu affiché.

**Livrable :**

* Fiche de découverte **HTML**.

### Lab 3 — Découvrir CSS

**Travail à faire :**

* Observer une page avec et sans CSS.
* Identifier le rôle de CSS.
* Repérer des règles de présentation.
* Relier CSS à l’apparence de l’interface.

**Livrable :**

* Fiche de découverte **CSS**.

### Lab 4 — Découvrir JavaScript

**Travail à faire :**

* Observer un script JavaScript simple.
* Identifier son rôle.
* Exécuter un petit exemple.
* Observer le résultat produit dans la console.

**Livrable :**

* Fiche de découverte **JavaScript**.

### Lab 5 — Découvrir le navigateur Web

**Travail à faire :**

* Identifier le navigateur comme outil d’accès à une application Web.
* Ouvrir une page Web.
* Observer son contenu.
* Identifier la relation entre code et rendu dans le navigateur.

**Livrable :**

* Fiche de découverte **Navigateur Web**.

### Lab 6 — Découvrir VS Code

**Travail à faire :**

* Identifier VS Code comme environnement de développement.
* Ouvrir un dossier de travail.
* Créer un fichier simple.
* Modifier et enregistrer le fichier.

**Livrable :**

* Dossier de travail préparé dans VS Code.

### Lab 7 — Découvrir Google Drive / Google Slides

**Travail à faire :**

* Accéder à un document partagé.
* Identifier le principe de partage.
* Consulter une ressource collaborative.
* Déposer ou modifier une production selon les consignes.

**Livrable :**

* Première production collaborative partagée.

**Résultat des Labs :** L’apprenant est capable d’identifier le rôle de HTML, CSS, JavaScript, du navigateur Web, de VS Code et de Google Drive / Google Slides dans le contexte de la formation.
