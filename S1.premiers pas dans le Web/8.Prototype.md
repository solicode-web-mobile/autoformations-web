## Prototype — Portfolio

**Objectif :** Reproduire l’analyse initiale dans un contexte différent en identifiant le contexte, les acteurs et les premières données d’une application Portfolio.

**Travail à faire :**

* Observer le support fourni pour le Portfolio.
* Identifier l’application et sa finalité.
* Identifier les acteurs.
* Identifier les rôles des acteurs.
* Identifier les principales fonctionnalités visibles.
* Identifier les premières données nécessaires au fonctionnement de l’application.

**Livrable :**

* Analyse initiale du contexte du Portfolio.
* Acteurs et rôles identifiés.
* Liste initiale des principales données.
