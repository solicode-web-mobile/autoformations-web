# Comment apprendre à Solicode ?

À Solicode, vous apprenez surtout **en faisant**.

Vous ne commencez pas toujours par un cours avec le formateur. Vous commencez par **lire, pratiquer, chercher et réaliser**.

Le formateur vous accompagne pendant votre travail. Il observe, aide, corrige et complète les explications lorsque cela est nécessaire.

## 1. Apprendre avec les tutoriels

Chaque Session peut commencer par des **tutoriels préparés**.

Un tutoriel vous montre une notion et les étapes pour réaliser un travail.

Vous devez :

**Lire → Comprendre → Reproduire → Tester**

Vous pouvez travailler seul ou échanger avec les autres apprenants.

Lorsque suffisamment d’apprenants ont terminé, un apprenant peut être choisi pour réaliser un **Live Coding**.

Il montre son travail et explique ce qu’il a fait.

Le formateur vérifie la compréhension et complète les explications.

**Vous apprenez donc en faisant et en expliquant.**

## 2. Chercher avec les Labs

Un **Lab** est proposé lorsqu’une recherche ou une expérimentation est utile.

Vous pouvez chercher :

* dans Internet ;
* dans la documentation ;
* dans des exemples.

Vous testez ensuite la solution trouvée.

Vous apprenez ainsi à résoudre un problème sans attendre directement la réponse du formateur.

**Chercher → Tester → Trouver une solution**

Un Lab n’est pas nécessaire dans toutes les Sessions.

## 3. S’entraîner avec le Prototype

Avant de réaliser une partie importante du Projet Fil Rouge, vous réalisez un **Prototype**.

Le Prototype est une réalisation plus petite.

Son objectif est de vous permettre de **vous entraîner avec les acquis de la Session**.

Exemple :

**Tutoriel :** apprendre à réaliser une page.

**Prototype :** réaliser une page détail d’un projet du Portfolio.

Vous utilisez donc ce que vous avez appris, mais dans un autre contexte.

Le Prototype permet de voir rapidement :

* ce que vous avez compris ;
* ce qui est encore difficile ;
* ce que vous devez corriger.

Vous êtes ainsi mieux préparé pour réaliser le projet complet.

## 4. Réaliser le Projet Fil Rouge

Le **Projet Fil Rouge** est construit progressivement pendant la formation.

Chaque étape de construction correspond à un **Sprint**.

Par exemple :

**Page d’accueil → Page détail d’un article → Gestion des catégories → Gestion des articles**

Dans chaque Sprint, vous réutilisez les connaissances apprises dans les tutoriels, les Labs et le Prototype.

Vous passez progressivement de petites réalisations à des réalisations plus complètes.

## 5. Présenter son travail

À certaines étapes, vous devez présenter votre travail.

Vous expliquez :

**ce que vous avez appris → ce que vous avez réalisé → comment vous l’avez réalisé**

Présenter votre travail vous aide à mieux comprendre ce que vous avez fait.

## 6. Ce qu’il faut retenir

Dans une Session, vous avancez progressivement :

**Tutoriel** → apprendre les bases.

**Lab** → chercher et expérimenter lorsque c’est nécessaire.

**Prototype** → s’entraîner dans un petit contexte.

**Projet Fil Rouge** → réutiliser les acquis dans une réalisation complète.

**Présentation** → expliquer et montrer son travail.

La formation vous fait donc progresser de :

**Je découvre → Je réalise → Je comprends → Je cherche → Je m’entraîne → Je construis.**

## 7. Travail à faire

Dans **Google Slides**, réalisez un schéma qui présente les étapes d’une Session :

**Tutoriels → Labs si nécessaire → Prototype → Projet Fil Rouge → Présentation**

Sous chaque étape, écrivez une phrase qui explique :

**ce que vous faites** et **ce que vous apprenez**.

Présentez ensuite votre schéma devant les autres apprenants.

**Résultat attendu :** vous savez expliquer comment vous allez apprendre et travailler pendant une Session à Solicode.
