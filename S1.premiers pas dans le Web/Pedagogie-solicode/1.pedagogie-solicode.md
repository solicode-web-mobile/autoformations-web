# Tutoriel — Comprendre la pédagogie active à Solicode

Comprendre comment se déroule une Session et comment vous passez de l’apprentissage à la réalisation.

**Prérequis** : navigateur, Internet et Google Slides.

# Partie 1 — Comprendre

## 1.1. Pédagogie active

<!-- Donner une définition claire, et donner un exemple comment on appliquer la pédagogie active -->

La pédagogie active signifie **apprendre en faisant**.

Vous :

**observez → apprenez → cherchez → pratiquez → réutilisez**

Le formateur vous accompagne. Vous réalisez le travail.

## 1.2. La progression

<!-- Il ne faut pas expliquer : **Imitation → Adaptation → Transposition**, il fuat expliquer ces phase, donnner des titre facile à comrendre par un débutant -->
Une Session suit une progression simple :

**Imitation → Adaptation → Transposition**

* **Imitation** : reproduire un exemple.
* **Adaptation** : utiliser les acquis dans un nouveau contexte.
* **Transposition** : réutiliser les acquis dans le Projet fil rouge.

## 1.3. La Session

<!-- Expliquer la notio  de sprint et projet file rouge, pour comprndre c'est quoi une session -->

Une Session organise les activités nécessaires pour avancer dans un Sprint.

La démarche est :

**Apprentissage → Lab → Prototype → Évaluation → Projet fil rouge → Présentation**

# Partie 2 — Reproduire avec S1

## 2.1. Apprentissage - Tutoriels

Dans **S1 — Premiers pas dans le Web**, vous découvrez le Web, le métier de développeur et les bases de JavaScript.

## 2.2. Lab : 

les lab n'existe pas toujour dans une session

Vous recherchez des informations, observez des exemples et expérimentez.

## 2.3. Prototype

un prototype prépare 

Vous appliquez les acquis au **Portfolio**.

Vous définissez :

* le contexte ;
* les acteurs ;
* les principales actions.

C’est l’**Adaptation**.

## 2.4. Projet fil rouge

Vous choisissez un sujet parmi les **20 sujets proposés**.

Puis vous définissez :

* le contexte ;
* les acteurs ;
* les principales actions.

C’est la **Transposition**.

## 2.5. Présentation

Vous présentez ce que vous avez appris et réalisé.

**Résultat attendu :** vous comprenez comment une Session transforme un apprentissage en réalisation.

# 4. Glossaire

* **Pédagogie active** : apprendre en faisant.
* **Lab** : activité de recherche et d’expérimentation.
* **Prototype** : première réalisation pour appliquer un apprentissage.
* **Projet fil rouge** : projet réalisé progressivement pendant la formation.
* **Imitation** : reproduire un exemple.
* **Adaptation** : utiliser un apprentissage dans un nouveau contexte.
* **Transposition** : réutiliser un apprentissage dans le Projet fil rouge.
