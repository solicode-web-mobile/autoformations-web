# Tutoriel 121.11 — Manipuler les variables et les entrées-sorties

Comprendre les variables, les entrées, les traitements simples et les sorties en JavaScript.

**Prérequis** : savoir exécuter JavaScript dans la console ou avec VS Code.

# Partie 1 — Théorie

## 1.1. Variable

Une **variable** permet de stocker une valeur.

```javascript
let prix = 100;
let titre = "Mon article";
```

## 1.2. Entrée

Une **entrée** est une valeur reçue par le programme.

```javascript
let quantite = Number(prompt("Quantité ?"));
```

## 1.3. Sortie

Une **sortie** permet d’afficher un résultat.

```javascript
console.log("Prix :", prix);
```

## 1.4. Traitement

Un **traitement** utilise les données pour produire un résultat.

```javascript
let total = prix * quantite;
```

## 1.5. À retenir

* **Variable** → stocker une valeur.
* **Entrée** → recevoir une valeur.
* **Traitement** → calculer ou transformer une valeur.
* **Sortie** → afficher un résultat.

# Partie 2 — Pratique

## 2.1. Niveau 1 — Manipuler des variables

### Étape 1 — Créer le programme

Créez un fichier `article.js`.

Ajoutez :

```javascript
let titre = "Livre JavaScript";
let prix = 80;
let quantite = 2;
```

### Étape 2 — Afficher les valeurs

Ajoutez :

```javascript
console.log("Titre :", titre);
console.log("Prix :", prix);
console.log("Quantité :", quantite);
```

### Étape 3 — Calculer le total

Ajoutez :

```javascript
let total = prix * quantite;

console.log("Total :", total);
```

**Résultat attendu :**

```text
Titre : Livre JavaScript
Prix : 80
Quantité : 2
Total : 160
```

---

## 2.2. Niveau 2 — Utiliser des entrées

### Étape 4 — Recevoir les données

Remplacez les valeurs de `prix` et `quantite` par des entrées :

```javascript
let titre = "Livre JavaScript";
let prix = Number(prompt("Prix ?"));
let quantite = Number(prompt("Quantité ?"));
```

### Étape 5 — Calculer le sous-total

Ajoutez :

```javascript
let sousTotal = prix * quantite;
```

### Étape 6 — Ajouter une remise

Demandez une remise :

```javascript
let remise = Number(prompt("Remise (%) ?"));
```

Calculez le montant de la remise :

```javascript
let montantRemise = sousTotal * remise / 100;
```

### Étape 7 — Calculer le total

Calculez le total final :

```javascript
let total = sousTotal - montantRemise;
```

### Étape 8 — Afficher le résultat

Ajoutez :

```javascript
console.log("Article :", titre);
console.log("Prix :", prix);
console.log("Quantité :", quantite);
console.log("Sous-total :", sousTotal);
console.log("Remise :", montantRemise);
console.log("Total :", total);
```

**Résultat attendu :**

Avec :

```text
Prix : 100
Quantité : 3
Remise : 10
```

le programme affiche :

```text
Article : Livre JavaScript
Prix : 100
Quantité : 3
Sous-total : 300
Remise : 30
Total : 270
```

### Étape 9 — Tester avec d’autres valeurs

Relancez le programme avec plusieurs prix, quantités et remises.

Observez les résultats.

# 3. Bilan

**Vous avez réalisé :** deux programmes JavaScript utilisant des variables, des entrées, des calculs et des sorties.

**Vous savez maintenant :** stocker des valeurs, recevoir des données, effectuer plusieurs calculs simples et afficher les résultats.

# 4. Glossaire

* **Variable** : espace qui stocke une valeur.
* **Entrée** : donnée reçue par le programme.
* **Sortie** : résultat affiché par le programme.
* **Traitement** : opération réalisée sur des données.
* **Remise** : réduction appliquée à un prix.
* **Console** : espace permettant d’afficher les résultats d’un programme.
