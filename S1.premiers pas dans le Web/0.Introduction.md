# S1 — Premiers pas dans le Web

## Objectif

Découvrir le Web, le métier de développeur et les bases de la programmation avec JavaScript.

À la fin de la Session, l’apprenant sait identifier le contexte et les acteurs d’une application, comprendre le rôle des données et réaliser un traitement simple avec JavaScript.

## Sprint 1 : Définir son projet fil rouge

Commencer le Projet fil rouge.

L’apprenant :

* choisit un sujet parmi les 20 sujets proposés ;
* découvre le contexte de l’application ;
* identifie les principaux acteurs ;
* décrit les principales actions des acteurs.

## Prototype

Réaliser le même travail sur le **Portfolio de l’apprenant**.

L’apprenant :

* définit le contexte du Portfolio ;
* identifie les acteurs ;
* décrit les principales actions des acteurs.

**Résultat attendu :** le contexte et les acteurs du Portfolio sont définis.

## Projet fil rouge

Choisir le sujet du Projet fil rouge parmi les 20 sujets proposés.

Puis définir les premiers éléments de l’application :

* le sujet ;
* le contexte ;
* les acteurs ;
* les principales actions des acteurs.

**Résultat attendu :** le sujet du Projet fil rouge est choisi et son contexte ainsi que ses acteurs sont définis.
