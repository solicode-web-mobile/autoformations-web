# Introduction — Session 1

## Objectif de la session

Découvrir le métier de développeur et les premières étapes de réalisation d’une application Web.

À la fin de la session, vous devez être capable de **comprendre un besoin simple, identifier les données, manipuler des variables et réaliser un petit programme JavaScript**.

## Les Labs

### Lab 1 — Découvrir le Web et Internet

Découvrir Internet, le Web, le navigateur, le site Web et l’application Web.

**Livrable :** présentation courte des notions découvertes.

### Lab 2 — Découvrir le métier de développeur

Découvrir les 5 missions d’un développeur :

**Comprendre le besoin → Créer l’application → Tester l’application → Mettre l’application en ligne → Travailler en équipe**

**Livrable :** présentation courte des 5 missions.

### Lab 3 — Découvrir HTML, CSS, JavaScript et PHP

Comprendre le rôle de chaque technologie dans une application Web.

**Livrable :** présentation courte des technologies.

### Lab 4 — Découvrir VS Code

Découvrir un environnement de développement et créer un premier fichier de code.

**Livrable :** premier dossier de travail dans VS Code.

## Les unités d’apprentissage

### UA.111.11 — Identifier le contexte et les acteurs

À partir des maquettes du **Blog personnel**, identifier :

**Application → Finalité → Périmètre → Acteurs → Rôles**

**Livrable :** analyse du contexte et des acteurs.

### UA.112.11 — Comprendre le rôle des données dans une application

Identifier les principales données utilisées par les fonctionnalités du Blog personnel.

**Livrable :** liste des données associées aux fonctionnalités.

### UA.121.11 — Manipuler les variables et les entrées-sorties

Construire un traitement JavaScript simple permettant de :

**stocker → recevoir → calculer → afficher**

**Livrable :** programme JavaScript simple.

### UA.121.12 — Déboguer un programme JavaScript

Utiliser VS Code pour exécuter un programme **ligne par ligne**, observer les variables et corriger une erreur simple.

**Livrable :** programme corrigé et fonctionnel.

## Mini-projet — Calculer une commande

Le mini-projet consiste à créer un petit programme JavaScript pour calculer le prix d’une commande.

Le programme doit demander :

* le nom du produit ;
* le prix ;
* la quantité ;
* la remise.

Il doit ensuite calculer :

**Sous-total → Montant de la remise → Total**

Puis afficher les résultats.

**Livrable :** un fichier `commande.js` fonctionnel.

## Progression de la session

**Labs → Tutoriels → Exercices → Prototype → Projet Fil Rouge**

Les Labs permettent de découvrir.

Les tutoriels permettent de comprendre et reproduire.

Les exercices permettent de pratiquer.

Le Prototype permet d’adapter les acquis.

Le Projet Fil Rouge permet de réutiliser les acquis dans le projet.
