# S1 : Premiers pas dans le Web

Découvrir le fonctionnement d’une application Web, comprendre le projet cible, identifier son contexte et ses acteurs et construire les premiers traitements JavaScript dans le Sandbox Algorithmique.


## Description

L’apprenant découvre le cadre général du parcours et le fonctionnement d’une application Web avant de commencer sa réalisation. Il observe la maquette du Blog personnel afin d’identifier sa finalité générale, son contexte fonctionnel, son périmètre et ses principaux acteurs. Il découvre également le rôle des données dans une application et identifie les premières données nécessaires à son fonctionnement. En parallèle, il construit les premiers traitements JavaScript dans le **Sandbox Algorithmique** en utilisant des variables, des valeurs, des entrées et des sorties. Il découvre enfin les principaux outils utilisés pendant la formation à travers des Labs. Aucune page Web n’est construite dans ce Sprint.

## Labs de découverte

**Objectif :** Comprendre les principaux éléments qui interviennent dans la réalisation et l’utilisation d’une application Web.





## Livrable

- Petit programme JavaScript exécuté en console.
- Programme utilisant des variables, des valeurs, des entrées simples, un calcul et une sortie console.


## Résultat attendu du Sprint

À la fin du Sprint, l’apprenant doit être capable de **comprendre le contexte général d’une application Web à partir d’une maquette, identifier sa finalité, son périmètre et ses acteurs, identifier les premières données nécessaires à son fonctionnement et construire un traitement JavaScript simple utilisant des variables, des entrées, des calculs et des sorties**.
