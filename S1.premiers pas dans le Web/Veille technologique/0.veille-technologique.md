# Introduction

## Découvrir le monde du développement Web

Bienvenue dans les premiers Labs de votre formation.

Ces Labs ont pour objectif de vous faire découvrir **le Web, Internet et le métier de développeur**.

Vous allez observer des sites Web, utiliser des outils, lire des exemples, faire de petites expériences et rechercher des informations sur Internet.

Vous ne devez pas seulement lire.

Vous devez **observer → comprendre → rechercher → tester → expliquer**.

## Les thèmes des Labs

Vous allez découvrir progressivement :

**1. Web et Internet**
Comprendre ce qu’est le Web, comment on accède à une page Web et quels outils sont utilisés.

**2. Métier de développeur**
Découvrir le rôle du développeur, ses missions et son environnement de travail.

**3. HTML**
Découvrir comment HTML permet de structurer le contenu d’une page Web.

**4. CSS**
Découvrir comment CSS permet de modifier l’apparence d’une page Web.

**5. JavaScript**
Découvrir comment JavaScript permet d’ajouter des comportements à une page Web.

**6. VS Code**
Découvrir un outil utilisé par les développeurs pour créer et modifier du code.

## Votre méthode de travail

Pour chaque Lab :

1. **Lisez le tutoriel.**
2. **Observez les exemples.**
3. **Réalisez les manipulations demandées.**
4. **Recherchez des informations complémentaires sur Internet.**
5. **Notez les informations importantes.**
6. **Préparez une courte présentation.**

L’objectif est de commencer à travailler comme un développeur : **chercher une information, la comprendre, l'utiliser et expliquer ce que vous avez fait**.

## Présenter votre découverte

Après chaque Lab, vous devez présenter votre travail aux autres apprenants.

La présentation doit respecter ces règles :

* **3 slides maximum** ;
* **3 phrases maximum par slide** ;
* phrases courtes et simples ;
* exemples, images ou captures d’écran lorsque cela est utile.

Votre présentation ne doit pas reprendre tout le tutoriel.

Elle doit montrer **les informations les plus importantes que vous avez comprises**.

## Résultat attendu

À la fin de ces Labs, vous devez avoir une première vision du **Web et du métier de développeur**.

Vous devez également reconnaître le rôle de **HTML, CSS, JavaScript et VS Code** et être capable d’expliquer simplement ce que vous avez découvert.
