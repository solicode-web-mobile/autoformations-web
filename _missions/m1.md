# M1 — Analyser et concevoir une solution logicielle

> **Niveau N1**

## Description

Comprendre un besoin à partir d'éléments existants, identifier les fonctionnalités et les données nécessaires, puis structurer les premiers éléments d'une solution logicielle dans un périmètre défini.

## Compétences

Les compétences associées à cette mission sont :

- C.111 — Analyser un besoin existant
- C.112 — Modéliser les données
- C.121 — Construire le traitement logique

## Domaines

La mission peut regrouper plusieurs domaines d'apprentissage.

Exemple :

```text
M1 — Analyser et concevoir une solution logicielle
│
├── C.111 — Analyser un besoin existant
│   └── D.111.1
│
├── C.112 — Modéliser les données
│   └── D.112.1
│
└── C.121 — Construire le traitement logique
    └── D.121.1
