title: "Construire le MLD"
layout: ua
code: "UA.112.15"
ordre: 20
competence: "C.112"
domaine: "D.112.1"
duree: 2
objectif: >
  Transformer le MCD en modèle relationnel composé de tables, colonnes et clés.
description: >
  Traduire le modèle conceptuel (MCD) en modèle logique (MLD) prêt à être implémenté dans une base de données relationnelle.
notions:
  - "Modèle Logique de Données (MLD)"
  - "Table, colonne, ligne (enregistrement)"
  - "Clé primaire (PK)"
  - "Clé étrangère (FK)"
  - "Transformation d'une relation 1-N"
  - "Transformation d'une relation N-N (table de liaison)"
livrable: >
  Le Modèle Logique de Données (MLD) complet.
travail_a_faire: >
  Appliquer les règles de passage du MCD au MLD : transformer les entités en tables, définir les clés primaires, ajouter les clés étrangères pour les relations 1-N, et créer les tables de liaison pour les relations N-N.
