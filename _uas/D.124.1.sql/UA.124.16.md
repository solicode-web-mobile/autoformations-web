  Construire une requête SQL combinant plusieurs opérations simples afin d’obtenir précisément les données recherchées.

  - "Combinaison de critères multiples"
  - "Recherche multicritère d'un utilisateur (email + statut)"
livrable: >
  Requête SQL SELECT combinant plusieurs critères logiques pour retrouver un utilisateur spécifique dans la base de données.
travail_a_faire: >
  Écrire et exécuter une requête SQL combinant plusieurs filtres avec AND et OR pour sélectionner un utilisateur selon son email et son rôle dans la table des utilisateurs.
