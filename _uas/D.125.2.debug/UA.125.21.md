objectif: >
  Utiliser les outils de développement du navigateur pour observer l’exécution d’un programme pas à pas, poser un point d'arrêt et corriger une anomalie.
description: >
  Découvrir le débogage avec les DevTools du navigateur. Poser un point d'arrêt (breakpoint) dans un script JavaScript, 
  suivre l'exécution ligne par ligne avec Step Over, inspecter les variables dans le panneau Scope et corriger le problème identifié.
notions:
  - "Outils de développement du navigateur (F12)"
  - "Onglet Sources / Débogueur"
  - "Points d'arrêt (breakpoints)"
  - "Exécution pas à pas (Step Over - F10)"
  - "Panneau des variables locales (Scope)"
  - "Résolution d'un dysfonctionnement dans le code"
livrable: >
  Script JavaScript débogué et exécuté sans anomalie après résolution du problème.
travail_a_faire: >
  Ouvrir les DevTools du navigateur, poser un point d'arrêt dans le script JavaScript, suivre l'exécution pas à pas avec Step Over pour repérer l'instruction défaillante, et modifier le code pour obtenir le résultat attendu.
