# UA.111.11 — Identifier le contexte et les acteurs

> **C.111 — Analyser un besoin existant**  
> **D.1.1.1.1 — Analyser un besoin existant**  
> **S1 — Comprendre le projet et premiers traitements logiques**

## Objectif

Comprendre la finalité d’une application et repérer les acteurs qui interviennent dans le système.

## Ce que vous allez apprendre

Vous allez apprendre à :

- comprendre la finalité d’une application ;
- identifier son contexte ;
- définir son périmètre ;
- identifier les acteurs ;
- préciser le rôle de chaque acteur.

```text

    ↓

````

## Travail à faire

À partir des maquettes d’un **Blog personnel** :

1. identifier l’application ;
2. identifier sa finalité ;
3. identifier les acteurs ;
4. identifier le rôle de chaque acteur.

Les acteurs attendus sont :
