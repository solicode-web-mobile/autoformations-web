Oui. À partir du domaine **D.122.1 — Structurer une interface avec HTML**, je recommande de construire les 3 UA comme une progression :

**HTML débutant → HTML intermédiaire → HTML avancé**

Le découpage doit suivre une logique pédagogique : **construire une page simple → structurer une interface complète → construire une structure HTML robuste et accessible**.

### UA 1 — HTML débutant

**Titre :** Construire la structure de base d’une page HTML

**Objectif d’apprentissage :**
Construire une page HTML simple à partir d’une conception existante en utilisant la structure de base du document, les principaux éléments de contenu et les ressources simples.

**Notions à apprendre :**

* `<!DOCTYPE html>`
* `<html>`
* `<head>`
* `<body>`
* `lang`
* balise ouvrante et fermante
* élément
* attribut
* valeur d’attribut
* `<title>`
* `<meta charset>`
* `<h1>` à `<h6>`
* `<p>`
* `<br>`
* `<hr>`
* `<div>`
* `<span>`
* `<ul>`
* `<li>`
* `<a>`
* `href`
* `<img>`
* `src`
* `alt`
* `width`
* `height`
* `<figure>`
* `<figcaption>`
* `class`
* chemins relatifs
* `alt`
* hiérarchie des titres

**Réalisation :**
Reproduire une page Web simple à partir d’une conception existante.

**Livrable :**
Une page HTML simple, correctement structurée, avec textes, liens, images et listes.

### UA 3 — HTML avancé

**Titre :** Construire une structure HTML sémantique, accessible et adaptable

**Objectif d’apprentissage :**
Construire une structure HTML robuste en choisissant les éléments selon leur rôle, en organisant les différentes zones de l’interface et en prenant en compte l’accessibilité et les différents écrans.

**Notions à apprendre :**

* choix des éléments sémantiques selon le rôle du contenu
* organisation complète d’une page
* `<header>`
* `<main>`
* `<section>`
* `<article>`
* `<nav>`
* `<aside>`
* `<footer>`
* organisation des zones répétitives
* `<thead>`
* `<tbody>`
* `<tfoot>`
* `colspan`
* `rowspan`
* cellules fusionnées
* `<fieldset>`
* `<legend>`
* contrôles accessibles
* `pattern`
* combinaison de contraintes de validation
* attributs spécifiques aux formulaires
* attributs des médias
* éléments interactifs
* `<picture>`
* `<source>`
* choix d’image selon l’écran
* organisation des commentaires
* conventions de nommage
* utilisation cohérente de `class` et `id`
* structure complète des ressources
* métadonnées SEO
* Open Graph
* autres métadonnées sociales
* gestion structurée des ressources externes

**Réalisation :**
Construire la structure HTML complète d’une interface à partir d’une conception, en choisissant les éléments selon leur rôle et en intégrant les contraintes d’accessibilité et d’adaptation.

**Livrable :**
Une interface HTML complète, sémantique, accessible et organisée pour être réutilisée avec CSS et JavaScript.

### Progression des trois UA

| UA                     | Niveau            | Finalité                                                     |
| ---------------------- | ----------------- | ------------------------------------------------------------ |
| **HTML débutant**      | Construire        | Reproduire une page HTML simple                              |
| **HTML intermédiaire** | Structurer        | Construire une interface plus complète                       |
| **HTML avancé**        | Professionnaliser | Construire une structure sémantique, accessible et adaptable |

Le point important est que **l’UA débutante ne doit pas contenir les formulaires, tableaux ou éléments sémantiques complexes**. Ils apparaissent progressivement dans l’UA intermédiaire, puis l’UA avancée traite surtout du **choix pertinent des éléments, de l’accessibilité, de l’adaptation et de la structuration professionnelle**.
