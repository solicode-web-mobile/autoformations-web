## 1. Objectif

Cloner, préparer, créer un commit et envoyer avec VS Code.

## 2. Prérequis

* Un compte GitHub et un dépôt.
* VS Code et Git installés.

## Partie 1 — Pratique

### 1.1. Cloner

#### Étape 1 — Lancer le clonage

Ouvrez le panneau **Contrôle de code source** dans VS Code.

Cliquez sur **Cloner le dépôt** et collez l'URL.

### 1.2. Préparer (Staging)

#### Étape 2 — Ajouter un fichier

Modifiez un fichier et enregistrez.

Dans le panneau, cliquez sur le bouton **+** à côté du fichier.

### 1.3. Commit

#### Étape 3 — Valider

Tapez un message court.

Cliquez sur **Valider (Commit)**.

### 1.4. Push

#### Étape 4 — Envoyer

Cliquez sur **Synchroniser les modifications**.
