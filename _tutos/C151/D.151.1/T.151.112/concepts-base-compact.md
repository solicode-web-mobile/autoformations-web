## 1. Objectif

Comprendre la différence entre Git et GitHub.

## 2. Prérequis

Aucun prérequis technique.

## Partie 1 — Théorie

### 1.1. Les deux outils

Git gère l'historique de votre projet localement.

GitHub héberge votre projet sur Internet.

### 1.2. Relation

```text
Votre ordinateur (Git) <--> Synchronisation <--> Internet (GitHub)
```
