# Règles de Rédaction des Tutoriels Git N1

Ce document regroupe les consignes globales qui s'appliquent à **tous les tutoriels** du socle Git N1. Les rédacteurs doivent impérativement respecter ces règles pour garantir une pédagogie adaptée aux débutants (Niveau 1).

### Consignes globales de rédaction :

* **Niveau de langue :** Français A1-A2. Utilisez des phrases très courtes (une idée par phrase).
* **Verbes d'action :** Utilisez des consignes directes étape par étape (Exemple : "1. Ouvrez le terminal. 2. Tapez la commande.").
* **Découpage visuel :** Interdiction de faire de longs paragraphes. Utilisez des listes numérotées pour l'exécution technique.
* **Vocabulaire technique :** Gardez les mots clés (Terminal, Commande, Commit), mais expliquez-les simplement (ex: "Le terminal est une fenêtre noire pour donner des ordres à l'ordinateur").
* **Captures d'écran :** Prévoyez systématiquement d'ajouter une capture d'écran du résultat attendu dans le terminal ou VS Code pour rassurer l'apprenant.
