# Tuto 5 : La routine locale du développeur (Terminal)

## 1. Description du tutoriel
* **Objectif pédagogique :** Remplacer les boutons de VS Code par les vraies commandes en réalisant le cycle classique : `git status`, `git add`, `git commit`.
* **Unité d'Apprentissage :** UA.115.12 - Sauvegarder son travail localement (Ligne de commande)
* **Session :** Session 3

## 2. Résultat final attendu (Ce que l'apprenant fera)
À la fin de ce tutoriel, l'apprenant aura exécuté ce cycle dans son terminal :

```bash
git status
git add index.html
git status
git commit -m "Ajouter le titre de la page"
git status
```

## 3. Consigne spécifique de rédaction
* **Insister sur la couleur :** Expliquez très clairement que `git status` montre du rouge (non préparé) et du vert (préparé/staging). Dites à l'apprenant de taper `git status` avant ET après chaque commande pour comprendre ce qui se passe.
