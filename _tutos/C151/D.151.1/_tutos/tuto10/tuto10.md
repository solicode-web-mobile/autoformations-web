# Tuto 10 : Lire l'historique du projet avec `git log`

## 1. Description du tutoriel
* **Objectif pédagogique :** Lire la liste des modifications, comprendre l'identifiant unique d'un commit (hash) et voir comment le projet a évolué dans le temps.
* **Unité d'Apprentissage :** UA.115.15 - Explorer l'historique et annuler des erreurs simples
* **Session :** Session 9

## 2. Résultat final attendu (Ce que l'apprenant fera)
L'apprenant exécutera les commandes pour lire l'historique :

```bash
# Historique complet
git log

# Historique résumé
git log --oneline
```

## 3. Consigne spécifique de rédaction
* **La touche magique 'q' :** L'apprenant risque de rester coincé dans la vue longue de `git log`. Il faut écrire en gras, encadré, dès le début : "Pour sortir de l'historique, appuyez sur la touche 'q' de votre clavier".
