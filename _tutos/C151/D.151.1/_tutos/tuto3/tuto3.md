# Tuto 3 : Sauvegarder son code en un clic avec VS Code

## 1. Description du tutoriel
* **Objectif pédagogique :** Cloner un projet, sauvegarder (commit) et partager (push) en utilisant uniquement l'interface graphique de VS Code.
* **Unité d'Apprentissage :** UA.115.11 - Préparer l'environnement et déposer son premier travail avec VS Code
* **Session :** Session 2

## 2. Résultat final attendu (Ce que l'apprenant fera)
L'apprenant aura cliqué sur les éléments suivants dans VS Code :
1. Icône **Contrôle de code source** (à gauche).
2. Bouton **Cloner le dépôt**.
3. Bouton **+** (Ajouter les modifications).
4. Saisie d'un message et clic sur le bouton **Valider (Commit)**.
5. Clic sur le bouton **Synchroniser les modifications (Push)**.

## 3. Consigne spécifique de rédaction
* **Guidage visuel :** Décrivez très précisément les icônes (ex: "Cliquez sur l'icône avec les trois cercles reliés par des lignes à gauche de l'écran"). Les captures d'écran avec des flèches rouges sont indispensables ici.
