# Tuto 6 : Partager son travail sur Internet avec `git push`

## 1. Description du tutoriel
* **Objectif pédagogique :** Comprendre le lien entre le dépôt local et distant (`origin`) et envoyer ses modifications en ligne de commande.
* **Unité d'Apprentissage :** UA.115.13 - Synchroniser son travail avec GitHub
* **Session :** Session 5

## 2. Résultat final attendu (Ce que l'apprenant fera)
L'apprenant tapera la commande suivante pour envoyer ses commits sur GitHub :

```bash
git push
```

## 3. Consigne spécifique de rédaction
* **Simplicité avant tout :** L'apprenant a déjà cloné son projet, donc le lien distant existe déjà. Ne parlez pas de `git remote add`. Dites simplement : "Votre projet sait déjà où aller sur Internet. Tapez `git push` pour envoyer la valise (le commit)."
