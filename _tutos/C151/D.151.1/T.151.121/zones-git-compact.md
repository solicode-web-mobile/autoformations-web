## 1. Objectif

Comprendre les 3 zones de Git.

## 2. Prérequis

* Comprendre Git et GitHub.

## Partie 1 — Théorie

Le parcours d'une modification s'effectue en 3 étapes :

1. **Dossier de travail** : Vous modifiez vos fichiers.
2. **Zone de préparation** : Vous sélectionnez les modifications à sauvegarder.
3. **Dépôt Git** : Vous créez la sauvegarde (le commit).
