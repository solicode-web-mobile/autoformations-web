## 1. Objectif

Installer rapidement Visual Studio Code, l'outil nécessaire pour écrire votre code, et créer votre premier fichier.

## 2. Prérequis

* Un ordinateur sous Windows.
* Une connexion Internet.

## Partie 1 — Théorie

### 1.1. Visual Studio Code

**Visual Studio Code** (ou **VS Code**) est l'éditeur de code utilisé pour écrire et modifier vos pages web. 

**À retenir :** VS Code est l'outil indispensable de tout développeur.

## Partie 2 — Pratique

### 2.1. Télécharger l'éditeur

Allez sur le site officiel : [https://code.visualstudio.com/](https://code.visualstudio.com/) et cliquez sur **Download for Windows**.

### 2.2. Installer l'éditeur

Ouvrez le fichier que vous venez de télécharger. Suivez simplement les étapes en conservant toutes les options par défaut, puis cliquez sur **Install**.

### 2.3. Vérifier l'installation

Ouvrez **Visual Studio Code** une fois l'installation terminée.
Créez un nouveau fichier texte via **File > New Text File** et enregistrez-le (raccourci `Ctrl + S`) sous le nom `test.html`.

## Bilan

**Vous avez réalisé :** l’installation de votre éditeur de code.

**Vous savez maintenant :** télécharger VS Code, l'installer, l'ouvrir et y créer un fichier, ce qui vous prépare pour le reste du module.

## Glossaire

* **VS Code** : le logiciel de référence gratuit pour écrire et éditer du code.
