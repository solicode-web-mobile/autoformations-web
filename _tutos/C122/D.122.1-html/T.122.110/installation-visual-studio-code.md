## 1. Objectif

Installer Visual Studio Code et vérifier qu’il fonctionne.

## 2. Prérequis

* Un ordinateur sous Windows.
* Une connexion Internet.

# Partie 1 — Théorie

## 1.1. Visual Studio Code

**Visual Studio Code**, ou **VS Code**, est un éditeur de code.

Il permet d’écrire et de modifier du code.

**À retenir :**

VS Code est l’outil utilisé pour écrire le code.

# Partie 2 — Pratique

## 2.1. Télécharger VS Code

### Étape 1 — Ouvrir le site

Ouvrez votre navigateur et allez sur :

```text
https://code.visualstudio.com/
```

### Étape 2 — Télécharger

Cliquez sur **Download for Windows**.

## 2.2. Installer VS Code

### Étape 3 — Lancer l’installation

Ouvrez le fichier téléchargé.

Suivez les étapes proposées par l’installateur.

Gardez les options proposées par défaut.

Cliquez sur **Install**.

### Étape 4 — Ouvrir VS Code

À la fin de l’installation, ouvrez **Visual Studio Code**.

## 2.3. Vérifier l’installation

### Étape 5 — Créer un fichier

Dans VS Code :

1. Cliquez sur **File**.
2. Cliquez sur **New Text File**.
3. Enregistrez le fichier sous :

```text
test.html
```

**Résultat attendu :**

VS Code est installé et le fichier `test.html` est créé.

# Partie 3 — Bilan

**Vous avez réalisé :** l’installation de Visual Studio Code.

**Vous savez maintenant :** ouvrir VS Code et créer un fichier.

# Partie 4 — Glossaire

* **VS Code** : éditeur utilisé pour écrire du code.
* **Éditeur de code** : logiciel utilisé pour créer et modifier du code.
* **Fichier** : document enregistré sur l’ordinateur.
