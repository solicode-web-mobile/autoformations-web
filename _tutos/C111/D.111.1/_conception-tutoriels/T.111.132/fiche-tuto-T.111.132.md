### T.111.132 — Formaliser les fonctionnalités de l'Administrateur

**Objectif :** L'apprenant regroupe les actions, applique la règle de nommage, décrit les parcours et produit la synthèse finale pour la partie admin.

**Étape 1 : Regrouper les actions en Fonctionnalités (Acteur + Action + Élément)**
* **Travail à faire :** Reprenez la liste brute des actions de l'Administrateur (remplir le formulaire, cliquer sur supprimer, etc.). Comment les formuler selon la règle standard (Acteur + Action + Élément) par "Entité" (Articles, Catégories) ?
* **Réponse :** On obtient : "L'Administrateur ajoute un article", "L'Administrateur modifie une catégorie", etc.

**Étape 2 : Décrire le parcours d'une fonctionnalité**
* **Travail à faire :** Décrivez le parcours complet pour la fonctionnalité "Ajouter une catégorie" en utilisant le modèle : Acteur → Écran de départ → Action → Résultat.
* **Réponse :** *Administrateur → Page de gestion des catégories → Clique sur le bouton "Ajouter une catégorie" → Affichage du formulaire de création de catégorie*.

**Étape 3 : Produire la synthèse fonctionnelle de la partie admin**
* **Travail à faire :** Regroupez l'ensemble des fonctionnalités de l'Administrateur dans un tableau synthétique final.
* **Réponse :** Ce tableau sépare la gestion des Articles (Lister, Ajouter, Modifier, Supprimer) et la gestion des Catégories (Lister, Ajouter, Modifier, Supprimer).

**Conclusion :**
Vous avez structuré toutes les fonctionnalités de l'espace d'administration. Vous pouvez maintenant consolider ces informations dans votre document de réalisation final.
