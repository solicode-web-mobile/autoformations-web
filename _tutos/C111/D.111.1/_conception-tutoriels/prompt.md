# Prompt ChatGPT : Conception des tutoriels

Agis en tant qu'ingénieur pédagogique. Nous avons défini et planifié **9 tutoriels** pour le niveau débutant (N1) du domaine de compétence : **Analyser et formaliser un besoin fonctionnel existant** (basé sur l'analyse visuelle d'une maquette de Blog).

Voici la liste des tutoriels :
- T.111.111 — Comprendre le contexte et les espaces d’un Blog
- T.111.112 — Identifier les acteurs du Blog
- T.111.121 — Identifier les actions du Visiteur sur le Blog public
- T.111.122 — Organiser les actions du Visiteur
- T.111.131 — Identifier les actions de l’Administrateur
- T.111.132 — Organiser les actions de l’Administrateur
- T.111.141 — Transformer une action en fonctionnalité
- T.111.142 — Décrire une fonctionnalité avec acteur, écran, action et résultat
- T.111.143 — Produire la synthèse fonctionnelle du Blog

Ta mission est de rédiger la **fiche de conception** (et non le tutoriel final) pour chacun de ces 9 tutoriels. 
Pour chaque tutoriel, fournis une fiche contenant strictement :
1. **L'objectif du tutoriel**.
2. **Les notions de base à expliquer**.
3. **Les actions concrètes** que l'apprenant réalisera ou observera sur la maquette.

Ne rédige JAMAIS le texte que l'apprenant lira (pas de "Bonjour, dans ce tutoriel..."). Ton rôle est d'indiquer au futur rédacteur ce qu'il devra mettre dans le tutoriel.

De plus, génère un petit bloc de **"Consignes globales"** pour les rédacteurs (rappelant qu'ils devront cibler un public N1, utiliser un français A1-A2, des phrases courtes et des verbes d'action).
