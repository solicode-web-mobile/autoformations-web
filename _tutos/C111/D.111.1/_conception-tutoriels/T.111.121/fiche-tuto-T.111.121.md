### T.111.121 — Identifier les actions du Visiteur sur le Blog

**Objectif :** L’apprenant repère les actions possibles (liens, boutons, formulaires) pour le Visiteur.

**Étape 1 : Repérer les actions sur la page d'accueil et les catégories**
* **Travail à faire :** Observez les pages affichant des listes d'articles. Sur quoi le Visiteur peut-il cliquer ?
* **Réponse :** Il peut cliquer sur les liens du menu (Accueil, Catégories, À propos), cliquer sur une catégorie spécifique, ou cliquer sur "Lire la suite" d'un article.

**Étape 2 : Repérer les actions sur le détail d'un article**
* **Travail à faire :** Observez la page qui affiche un article complet. Que fait le Visiteur ici ?
* **Réponse :** Il lit le contenu complet de l'article (titre, auteur, date, texte).

**Étape 3 : Repérer l'action sur la page de connexion**
* **Travail à faire :** Observez la page de connexion. Que doit faire le Visiteur s'il veut s'authentifier (même s'il n'en a pas le droit en tant que simple visiteur) ?
* **Réponse :** Il doit remplir son Email, son Mot de passe, et cliquer sur le bouton "Se connecter".

**Conclusion :**
Vous avez repéré toutes les actions brutes possibles pour le Visiteur. Vous allez les lister dans la réalisation.
