## 1. Objectif

Vous allez apprendre à créer un planning simple pour organiser votre travail.

Vous allez apprendre à :

- lister les grandes tâches ;
- estimer une durée ;
- définir une échéance ;
- organiser les tâches dans un ordre logique.

## 2. Prérequis

Vous devez savoir :

- identifier une tâche ;
- définir un résultat attendu ;
- remplir une fiche de tâche ;
- lire une durée simple.

## Données de départ

Vous devez réaliser la page d'accueil d'un blog.

## Partie 1 — Théorie

### 1.1. La durée

La **durée** indique le temps nécessaire pour réaliser une tâche.

Exemple :

> Créer la structure HTML : 1 heure.

La durée est une estimation. Le temps réel peut être différent.

### 1.2. L'échéance

L'**échéance** indique le moment où une tâche doit être terminée.

Exemple :

> Terminer le HTML avant 14 h 00.

L'échéance permet de savoir quand le travail doit être terminé.

### 1.3. L'estimation

Une **estimation** est une durée prévue avant de commencer une tâche.

Exemple :

> Je prévois 1 heure pour créer le HTML.

L'estimation n'est pas forcément exacte.

Elle permet de préparer le travail.

### 1.4. L'ordre

L'**ordre** indique dans quelle séquence les tâches doivent être réalisées.

Exemple :

1. préparer la maquette ;
2. créer le HTML ;
3. ajouter le contenu ;
4. appliquer le CSS ;
5. tester la page.

L'ordre doit rester logique.

### 1.5. Le planning

Un **planning** regroupe les tâches, leur durée et leur échéance.

Exemple :

| Tâche | Durée estimée | Échéance |
|---|---:|---|
| Préparer la maquette | 1 h | 10 h 00 |
| Créer le HTML | 1 h 30 | 11 h 30 |
| Ajouter le contenu | 1 h | 12 h 30 |
| Appliquer le CSS | 1 h 30 | 14 h 00 |
| Tester la page | 1 h | 15 h 00 |

Le planning permet de voir le travail à réaliser dans le temps disponible.

### 1.6. À retenir

- Une tâche correspond à un travail à réaliser.
- La durée indique le temps prévu.
- L'échéance indique quand le travail doit être terminé.
- L'estimation est faite avant de commencer.
- L'ordre permet d'organiser les tâches.
- Le planning regroupe ces informations.

## Glossaire

- **Durée** : temps nécessaire pour réaliser une tâche.
- **Échéance** : moment prévu pour terminer une tâche.
- **Estimation** : durée prévue avant de commencer le travail.
- **Ordre** : position des tâches dans la réalisation du travail.
- **Planning** : document qui organise les tâches dans le temps.
