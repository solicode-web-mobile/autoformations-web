## 1. Objectif

Vous allez apprendre à maintenir votre suivi à jour pendant la réalisation d'un projet.

Vous allez apprendre à :

- mettre à jour l'état de vos tâches ;
- enregistrer les temps réalisés ;
- signaler les blocages ;
- rendre compte de votre avancement ;
- garder un suivi utilisable jusqu'à la fin du travail.

## 2. Prérequis

Vous devez savoir :

- définir le résultat attendu d'une tâche ;
- créer un planning simple ;
- découper une tâche en actions ;
- utiliser un tableau de suivi ;
- comparer le temps prévu et le temps réel ;
- signaler un blocage ;
- faire un compte rendu d'avancement.

## Données de départ

### Contexte

Vous réalisez un projet Web avec plusieurs tâches.

Vous utilisez différents outils pour suivre votre travail :

- une fiche de tâche ;
- un planning ;
- une liste d'actions ;
- un tableau de suivi ;
- un tableau des temps ;
- des messages SOS ;
- des comptes rendus.

Le suivi doit rester à jour pendant toute la réalisation.

Exemple :

| Tâche | État | Temps prévu | Temps réel |
|---|---|---:|---:|
| Connexion | Terminé | 1 h | 1 h 15 |
| Recherche d'un utilisateur | En cours | 1 h 30 | 1 h |
| Contrôle des accès | À faire | 2 h | |

Une modification du travail doit être reportée dans le suivi.

## Partie 1 — Théorie

### 1.1. Un suivi à jour

Un **suivi à jour** présente la situation réelle du travail.

Il doit correspondre à ce que vous avez réellement fait.

Exemple :

Une tâche est terminée.

Le tableau doit passer de :

> En cours

à :

> Terminé

### 1.2. Pourquoi mettre à jour le suivi ?

Un suivi à jour permet de savoir :

- ce qui est terminé ;
- ce qui est en cours ;
- ce qui reste à faire ;
- le temps utilisé ;
- les difficultés rencontrées.

Il permet aussi de préparer la suite du travail.

### 1.3. Quand mettre à jour le suivi ?

Mettez votre suivi à jour après une action importante.

Par exemple :

- une tâche est terminée ;
- une nouvelle tâche commence ;
- le temps réel est connu ;
- un blocage apparaît ;
- un blocage est résolu.

N'attendez pas la fin du projet pour tout mettre à jour.

### 1.4. Garder les informations cohérentes

Les différents éléments du suivi doivent correspondre.

Exemple :

Le tableau indique :

> Connexion — Terminé

Le compte rendu ne doit pas dire :

> Connexion — En cours

Les informations doivent représenter la même situation.

### 1.5. Le suivi comme outil de travail

Le suivi n'est pas seulement un document à remplir.

Il sert à organiser le travail pendant sa réalisation.

Il permet de voir la situation et de décider de la prochaine action.

### 1.6. À retenir

Un bon suivi est :

- à jour ;
- clair ;
- cohérent ;
- simple à utiliser.

Mettez-le à jour pendant le travail.

Ne le complétez pas seulement à la fin.

## Partie 2 — Pratique

### 2.1. Préparer le suivi

Reprenez les tâches du projet.

Exemple :

| Tâche | État | Temps prévu | Temps réel |
|---|---|---:|---:|
| Connexion | Terminé | 1 h | 1 h 15 |
| Recherche d'un utilisateur | En cours | 1 h 30 | 1 h |
| Contrôle des accès | À faire | 2 h | |

Vérifiez que les informations correspondent à votre situation réelle.

### 2.2. Mettre à jour les états

Supposons que vous avez terminé la recherche d'un utilisateur.

Modifiez son état :

| Tâche | État |
|---|---|
| Connexion | Terminé |
| Recherche d'un utilisateur | Terminé |
| Contrôle des accès | À faire |

La tâche terminée ne doit plus apparaître comme **En cours**.

### 2.3. Ajouter le temps réel

Notez le temps réellement utilisé.

Exemple :

| Tâche | Temps prévu | Temps réel |
|---|---:|---:|
| Connexion | 1 h | 1 h 15 |
| Recherche d'un utilisateur | 1 h 30 | 1 h 20 |
| Contrôle des accès | 2 h | |

Ne remplissez pas le temps réel d'une tâche qui n'a pas encore été réalisée.

### 2.4. Signaler un blocage

Si une tâche est bloquée, indiquez-le dans votre suivi.

Exemple :

> Contrôle des accès — Bloqué

Puis préparez un message SOS avec :

- le résultat attendu ;
- le problème observé ;
- les tentatives ;
- l'impact ;
- le besoin.

Le suivi doit montrer qu'une tâche est bloquée.

### 2.5. Mettre à jour l'avancement

À la fin d'une période de travail, vérifiez votre suivi.

Posez-vous ces questions :

1. Quelles tâches sont terminées ?
2. Quelle tâche est en cours ?
3. Quelles tâches restent à faire ?
4. Quel temps réel dois-je ajouter ?
5. Ai-je un blocage à signaler ?

Mettez les informations à jour.

### 2.6. Vérifier la cohérence

Comparez les différents éléments de votre suivi.

| Élément | Vérification |
|---|---|
| Tableau de suivi | Les états sont actuels. |
| Temps | Les temps réels sont renseignés après les tâches. |
| Blocages | Les problèmes sont signalés. |
| Compte rendu | Il correspond à l'état actuel. |
| Prochaines actions | Elles correspondent aux tâches restantes. |

Corrigez les informations qui ne correspondent plus à la situation réelle.

### 2.7. Réaliser le suivi global

Prenez maintenant une partie réelle de votre projet.

Mettez à jour :

- les tâches ;
- les états ;
- les temps ;
- les blocages ;
- l'avancement ;
- les prochaines actions.

Votre suivi doit présenter la situation réelle au moment où vous le produisez.

### 2.8. Produire le livrable

Préparez votre suivi global.

Il doit permettre à une autre personne de comprendre rapidement :

- ce qui est terminé ;
- ce qui est en cours ;
- ce qui reste à faire ;
- le temps déjà utilisé ;
- les éventuels blocages ;
- la prochaine étape.

**Livrable :**

Créez un document Markdown (ou un Google Doc) contenant votre suivi global actualisé.

**Critère de réussite :**

Le suivi correspond à l'état réel du travail. Les tâches, les temps, les blocages et l'avancement sont à jour et cohérents.

## Bilan

**Vous avez réalisé :** un suivi global actualisé de votre travail.

**Vous savez maintenant :** maintenir vos outils de suivi à jour pendant toute la réalisation d'un projet.

Vous pouvez utiliser le suivi pour organiser votre travail, repérer un problème et préparer la prochaine action.

## Glossaire

- **Suivi** : ensemble des informations qui permettent de suivre un travail.
- **À jour** : qui correspond à la situation réelle actuelle.
- **État** : situation actuelle d'une tâche.
- **Avancement** : progression d'un travail.
- **Blocage** : problème qui empêche de continuer une tâche.
- **Cohérent** : qui correspond aux autres informations du suivi.
- **Prochaine action** : action à réaliser ensuite.
