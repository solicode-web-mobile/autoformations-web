## 1. Objectif

Vous allez apprendre à faire un compte rendu simple de votre avancement.

Vous allez apprendre à :

- dire ce que vous avez terminé ;
- dire ce qu'il reste à faire ;
- signaler une difficulté ;
- présenter votre situation en peu de phrases.

## 2. Prérequis

Vous devez savoir :

- utiliser un tableau de suivi ;
- identifier les tâches terminées ;
- identifier les tâches restantes ;
- signaler un blocage ;
- décrire simplement une difficulté.

## Données de départ

### Contexte

Vous travaillez sur la gestion des articles dans l'espace d'administration du Blog.

Vous avez plusieurs tâches :

| Tâche | État |
|---|---|
| Ajouter un article | Terminé |
| Modifier un article | Terminé |
| Supprimer un article | En cours |
| Tester les actions | À faire |

Vous devez maintenant présenter votre avancement.

Votre compte rendu doit répondre à trois questions :

1. Qu'est-ce qui a été fait ?
2. Qu'est-ce qui reste à faire ?
3. Quelles sont les difficultés ?

## Partie 1 — Théorie

### 1.1. Un compte rendu d'avancement

Un **compte rendu d'avancement** présente la situation d'un travail à un moment donné.

Il permet de savoir rapidement :

- ce qui est terminé ;
- ce qui reste à faire ;
- ce qui pose problème.

Il doit être court et clair.

### 1.2. Ce qui a été fait

Commencez par présenter les tâches terminées.

Exemple :

> J'ai terminé l'ajout et la modification des articles.

Cette phrase indique votre travail réalisé.

### 1.3. Ce qui reste à faire

Indiquez ensuite les tâches qui ne sont pas terminées.

Exemple :

> Il reste la suppression des articles et les tests.

Cette information permet de connaître la suite du travail.

### 1.4. Les difficultés

Indiquez une difficulté si vous en avez rencontré une.

Exemple :

> J'ai eu un problème lors de la suppression d'un article.

Si vous avez déjà signalé le problème avec un message SOS, vous pouvez le rappeler brièvement.

Exemple :

> La suppression est encore bloquée.

### 1.5. Une structure simple

Pour un compte rendu court, utilisez trois parties :

| Partie | Question |
|---|---|
| Fait | Qu'ai-je terminé ? |
| Suite | Que reste-t-il à faire ? |
| Difficulté | Quel problème ai-je rencontré ? |

Vous pouvez donc utiliser cette forme :

> **Fait :** …  
> **Suite :** …  
> **Difficulté :** …

### 1.6. À retenir

Un compte rendu d'avancement doit être :

- court ;
- clair ;
- factuel ;
- à jour.

Il doit permettre à une autre personne de comprendre rapidement votre situation.

## Partie 2 — Pratique

### 2.1. Lire le tableau de suivi

Reprenez les informations suivantes :

| Tâche | État |
|---|---|
| Ajouter un article | Terminé |
| Modifier un article | Terminé |
| Supprimer un article | En cours |
| Tester les actions | À faire |

Identifiez :

- les tâches terminées ;
- les tâches restantes ;
- la difficulté éventuelle.

### 2.2. Écrire ce qui a été fait

Écrivez une phrase qui présente les tâches terminées.

Exemple de structure :

> J'ai terminé …

Utilisez uniquement les tâches qui sont réellement terminées.

### 2.3. Écrire ce qui reste à faire

Écrivez une phrase qui présente les tâches restantes.

Exemple de structure :

> Il reste …

Utilisez les tâches **En cours** et **À faire**.

### 2.4. Indiquer une difficulté

Indiquez une difficulté si elle existe.

Exemple :

> J'ai une difficulté avec la suppression d'un article.

Ne donnez pas une explication longue.

Si le problème est déjà décrit dans un message SOS, faites simplement référence au blocage.

### 2.5. Construire le compte rendu

Assemblez vos trois informations.

Utilisez cette structure :

> **Fait :** …  
> **Suite :** …  
> **Difficulté :** …

Votre compte rendu doit être compréhensible sans explication supplémentaire.

### 2.6. Vérifier le compte rendu

Relisez votre texte.

| Vérification | Oui / Non |
|---|---|
| Les tâches terminées sont indiquées ? | |
| Les tâches restantes sont indiquées ? | |
| Les difficultés sont indiquées ? | |
| Les informations correspondent au tableau de suivi ? | |
| Le texte est court et clair ? | |

Corrigez les informations qui ne correspondent pas à votre suivi.

### 2.7. Produire le livrable

Rédigez le compte rendu correspondant à votre situation réelle.

Si vous avez terminé plusieurs tâches, indiquez-les.

Si une tâche est encore en cours, indiquez-la.

Si vous avez rencontré une difficulté, indiquez-la brièvement.

**Livrable :**

Créez un document Markdown (ou un Google Doc) contenant votre bilan écrit d'avancement.

**Critère de réussite :**

Le compte rendu indique clairement ce qui a été fait, ce qui reste à faire et les difficultés rencontrées. Les informations correspondent au tableau de suivi.

## Bilan

**Vous avez réalisé :** un compte rendu court présentant votre avancement.

**Vous savez maintenant :** présenter clairement votre travail réalisé, les prochaines tâches et les difficultés rencontrées.

## Glossaire

- **Avancement** : état d'un travail à un moment donné.
- **Compte rendu** : texte court qui présente une situation ou un travail réalisé.
- **Tâche terminée** : tâche réalisée et vérifiée.
- **Tâche restante** : tâche qui n'est pas encore terminée.
- **Difficulté** : problème qui rend le travail plus difficile ou empêche de continuer.
