## 1. Objectif

Avant de commencer à coder, vous allez apprendre à définir clairement le résultat attendu d'une tâche.

Vous allez identifier :

- ce que vous devez réaliser ;
- ce qui est inclus dans la tâche ;
- les conditions à respecter ;
- comment vérifier que le travail est terminé.

## 2. Prérequis

Vous devez savoir :

- lire une consigne simple ;
- identifier une réalisation à produire ;
- utiliser un document Markdown ou un Google Doc.

## Données de départ

Vous devez réaliser la première page Web de votre projet de blog.

La consigne est la suivante :

> Créer une page d'accueil simple pour un blog.

>
> La page doit être réalisée avec HTML.
>
> Le résultat doit pouvoir être ouvert dans un navigateur.

Cette consigne contient plusieurs informations.

Votre travail consiste à les organiser avant de commencer le code.

## Partie 1 — Théorie

### 1.1. La tâche

Une **tâche** est un travail précis à réaliser.

Exemple :

> Créer la page d'accueil du blog.

La tâche indique ce que vous devez faire.

### 1.2. Le résultat attendu

Le **résultat attendu** décrit ce que vous devez obtenir à la fin de la tâche.

Exemple :

> Une page Web d'accueil simple pour le blog.

Le résultat doit être observable.

### 1.3. Le périmètre

Le **périmètre** indique ce qui fait partie de la tâche.

Il indique aussi ce qui ne fait pas partie de la tâche.

Pour cette tâche, le périmètre comprend :

- une page d'accueil ;
- du HTML ;
- un titre ;
- une présentation courte.

Le périmètre ne comprend pas, par exemple :

- une base de données ;
- une connexion utilisateur ;
- une administration.

### 1.4. Les conditions de réalisation

Les **conditions de réalisation** indiquent les règles à respecter pour réaliser la tâche.

Exemple :

- utiliser HTML ;
- respecter la structure HTML ;
- obtenir une page lisible dans un navigateur.

### 1.5. Le critère de réussite

Un **critère de réussite** permet de vérifier si la tâche est terminée.

Exemple :

> La page s'ouvre dans le navigateur et contient le titre et la présentation demandés.

### 1.6. À retenir

- Une tâche indique **quoi faire**.
- Le résultat attendu indique **quoi obtenir**.
- Le périmètre indique **ce qui est inclus**.
- Les conditions indiquent **les règles à respecter**.
- Le critère de réussite indique **comment vérifier le travail**.

## Glossaire

- **Tâche** : travail précis à réaliser.
- **Résultat attendu** : résultat que l'on doit obtenir à la fin du travail.
- **Périmètre** : éléments inclus dans la tâche.
- **Condition de réalisation** : règle à respecter pour réaliser la tâche.
- **Critère de réussite** : élément qui permet de vérifier que le travail est terminé.
