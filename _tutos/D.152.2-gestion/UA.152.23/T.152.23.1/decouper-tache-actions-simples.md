## 1. Objectif

Vous allez apprendre à découper une tâche en petites actions simples.

Vous allez apprendre à :

- transformer une tâche en plusieurs actions ;
- mettre les actions dans un ordre logique ;
- identifier une dépendance simple ;
- terminer le travail par une vérification.

## 2. Prérequis

Vous devez savoir :

- identifier une tâche ;
- définir son résultat attendu ;
- créer un planning simple ;
- organiser des tâches dans un ordre logique.

## Données de départ

### Contexte

Vous devez réaliser une page Web dans le cadre de votre projet.

Votre planning contient trois grandes parties :

- HTML ;
- CSS ;
- JavaScript.

Une grande tâche peut contenir plusieurs petites actions.

Exemple :

> Créer la page Web.

Cette tâche est trop générale pour suivre précisément le travail.

Elle peut être découpée en plusieurs actions :

- créer le fichier HTML ;
- créer la structure HTML ;
- ajouter le contenu ;
- créer le fichier CSS ;
- appliquer les styles ;
- tester la page.

Le code HTML fourni dans `data_html` sert de base pour les exercices du tutoriel.

## Partie 1 — Théorie

### 1.1. Une action

Une **action** est un petit travail que vous pouvez réaliser directement.

Exemple :

> Créer le fichier `index.html`.

Cette action est précise.

Vous savez quoi faire et quand elle est terminée.

### 1.2. Le découpage

Le **découpage** consiste à transformer une grande tâche en plusieurs petites actions.

Exemple :

> Réaliser la page Web.

Peut devenir :

1. créer le fichier HTML ;
2. créer la structure HTML ;
3. ajouter le contenu ;
4. créer le fichier CSS ;
5. appliquer les styles ;
6. tester la page.

Chaque action est plus facile à réaliser et à suivre.

### 1.3. L'ordre

Les actions doivent être placées dans un ordre logique.

Exemple :

Vous devez créer le fichier avant de modifier son contenu.

L'ordre peut donc être :

1. créer le fichier ;
2. ajouter la structure ;
3. ajouter le contenu ;
4. tester.

### 1.4. La dépendance simple

Une **dépendance** signifie qu'une action doit être réalisée avant une autre.

Exemple :

> Appliquer le CSS dépend de la création du fichier HTML.

Le HTML doit donc être disponible avant de travailler sur son style.

### 1.5. La vérification

La **vérification** permet de contrôler le résultat après les actions.

Exemple :

> Ouvrir la page dans le navigateur et vérifier son affichage.

La dernière action du découpage doit permettre de vérifier que le travail est correct.

### 1.6. À retenir

- Une grande tâche peut être divisée en petites actions.
- Une action doit être précise et réalisable.
- Les actions doivent suivre un ordre logique.
- Une dépendance indique qu'une action doit attendre une autre action.
- Le découpage doit se terminer par une vérification.

Reprenez vos actions.

Vérifiez leur ordre.

> Est-ce que cette action peut être réalisée maintenant ?

### 2.3. Ajouter la vérification

Votre travail doit se terminer par une action de vérification.

Ajoutez cette action à votre liste.

Elle doit permettre de vérifier que la partie HTML fonctionne.

### 2.5. Vérifier le découpage

Contrôlez votre liste.

- Chaque action correspond-elle à un travail précis ?

## Bilan

## Glossaire

- **Action** : petit travail précis à réaliser.
- **Découpage** : transformation d'une tâche en plusieurs actions.
- **Ordre** : position des actions dans la réalisation du travail.
- **Dépendance** : relation entre deux actions lorsqu'une action doit attendre une autre.
- **Vérification** : contrôle du résultat après la réalisation.
