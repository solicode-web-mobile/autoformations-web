# Tuto 1 : Installer et configurer Git sur son ordinateur

## 1. Description du tutoriel
* **Objectif pédagogique :** L'apprenant doit installer le logiciel Git sur son poste de travail et s'identifier (nom et email) pour que ses futures sauvegardes soient signées.
* **Unité d'Apprentissage :** UA.115.11 - Préparer l'environnement et déposer son premier travail avec VS Code
* **Session :** Session 2

## 2. Résultat final attendu (Ce que l'apprenant fera)
À la fin de ce tutoriel, l'apprenant aura exécuté avec succès les 3 commandes suivantes dans son terminal :

```bash
# 1. Vérifier que Git est bien installé
git --version

# 2. Configurer son prénom et nom
git config --global user.name "Prénom Nom"

# 3. Configurer son adresse email
git config --global user.email "email@exemple.com"
```

## 3. Consigne spécifique de rédaction
* **Explication ciblée :** Ne racontez pas l'histoire de Git. Dites simplement que la configuration `user.name` sert de "signature" obligatoire pour tous ses futurs travaux.
