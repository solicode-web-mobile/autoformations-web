# Tuto 8 : Créer et configurer un fichier `.gitignore`

## 1. Description du tutoriel
* **Objectif pédagogique :** Bloquer les fichiers systèmes et les dossiers inutiles de l'ordinateur pour garder un dépôt propre sur GitHub.
* **Unité d'Apprentissage :** UA.115.14 - Sécuriser son projet et ignorer l'inutile
* **Session :** Session 7

## 2. Résultat final attendu (Ce que l'apprenant fera)
L'apprenant créera un fichier nommé `.gitignore` contenant au moins les lignes suivantes :

```text
.DS_Store
Thumbs.db
node_modules/
.env
```
Et le sauvegardera avec `git add .gitignore` puis `git commit`.

## 3. Consigne spécifique de rédaction
* **Alerte sur le point :** Insistez bien sur le point au début du nom de fichier `.gitignore`. Montrez une capture d'écran de l'explorateur de fichiers VS Code avec ce fichier créé.
