# Tuto 4 : Les 3 zones de Git expliquées simplement

## 1. Description du tutoriel
* **Objectif pédagogique :** Comprendre le modèle mental (Dossier de travail -> Zone de préparation -> Dépôt).
* **Unité d'Apprentissage :** UA.115.12 - Sauvegarder son travail localement (Ligne de commande)
* **Session :** Session 3

## 2. Résultat final attendu (Ce que l'apprenant fera)
C'est un tutoriel conceptuel. L'apprenant doit comprendre le parcours d'un fichier avant d'être sauvegardé.

## 3. Consigne spécifique de rédaction
* **Métaphore de la salle d'attente :** 
  - *Dossier de travail :* L'atelier où on travaille.
  - *Zone de préparation (Staging) :* La salle d'attente ou la valise qu'on prépare.
  - *Dépôt (Commit) :* Le coffre-fort où on sauvegarde la valise.
