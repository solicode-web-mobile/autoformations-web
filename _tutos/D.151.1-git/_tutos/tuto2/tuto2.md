# Tuto 2 : Comprendre les concepts de base : Git et GitHub

## 1. Description du tutoriel
* **Objectif pédagogique :** Comprendre visuellement la différence entre l'outil local (Git) et le serveur distant (GitHub).
* **Unité d'Apprentissage :** UA.115.11 - Préparer l'environnement et déposer son premier travail avec VS Code
* **Session :** Session 2

## 2. Résultat final attendu (Ce que l'apprenant fera)
Ce tutoriel est 100% théorique. L'apprenant ne tape aucune commande, mais il doit assimiler le modèle mental.

## 3. Consigne spécifique de rédaction
* **Utilisation de métaphores :** Utilisez une image claire. Par exemple : "Git est l'appareil photo qui prend des clichés de votre code sur votre ordinateur. GitHub est l'album photo en ligne où vous publiez vos clichés pour les partager."
