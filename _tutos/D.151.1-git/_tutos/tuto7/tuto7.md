# Tuto 7 : Mettre à jour son ordinateur avec `git pull`

## 1. Description du tutoriel
* **Objectif pédagogique :** Apprendre à récupérer le code distant pour avoir un projet à jour avant de commencer à coder.
* **Unité d'Apprentissage :** UA.115.13 - Synchroniser son travail avec GitHub
* **Session :** Session 5

## 2. Résultat final attendu (Ce que l'apprenant fera)
L'apprenant tapera la commande suivante :

```bash
git pull
```

## 3. Consigne spécifique de rédaction
* **Scénario concret :** Donnez un exemple de la vie réelle. "Imaginez que vous avez travaillé sur les ordinateurs de l'école hier. Aujourd'hui, vous êtes chez vous. Avant de commencer à coder, vous devez récupérer ce que vous avez fait hier. Tapez `git pull`."
