# Comment apprendre à Solicode ?

À Solicode, vous apprenez surtout **en faisant**.

Vous ne devez pas seulement lire des informations ou écouter des explications. Vous devez utiliser ce que vous apprenez pour réaliser des activités et construire progressivement des projets.

La formation vous fait passer progressivement de :

**Apprendre → Pratiquer → Expliquer → Chercher → S’entraîner → Construire**

Cette méthode vous aide à devenir progressivement plus autonome dans votre travail de développeur.

## 1. Tutoriels — Apprendre les bases

Les **tutoriels** sont des supports préparés pour vous permettre d’apprendre en **autoformation**.

Vous commencez par lire le tutoriel. Vous observez les exemples et vous réalisez les étapes proposées.

Le principe est :

**Lire → Comprendre → Reproduire → Tester**

Le tutoriel vous donne les premières bases nécessaires pour réaliser le travail du Sprint.

### Apprendre avec les autres

Vous pouvez échanger avec les autres apprenants pendant votre travail.

Un apprenant peut expliquer une étape à un autre apprenant qui rencontre une difficulté.

Vous ne devez donc pas toujours attendre une réponse du formateur.

Vous pouvez :

**Chercher dans le tutoriel → essayer → demander à un camarade → comparer → corriger**

### Live Coding

Lorsque suffisamment d’apprenants ont réalisé le tutoriel, Active LMS peut choisir un apprenant pour réaliser un **Live Coding**.

L’apprenant reprend le travail devant le groupe et explique ce qu’il fait.

Le formateur participe au Live Coding.

Il vérifie que l’apprenant comprend la réalisation, corrige si nécessaire et complète les connaissances.

Le Live Coding permet donc de passer de :

**« J’ai réalisé le tutoriel »**

à :

**« Je comprends et je peux expliquer ce que j’ai réalisé. »**

### Impact sur l’apprentissage

Le tutoriel vous permet de construire les premières bases.

Le travail entre apprenants développe la collaboration.

Le Live Coding permet de confirmer la compréhension.

Vous apprenez donc progressivement à **travailler seul, travailler avec les autres et expliquer votre travail**.

## 2. Labs — Chercher et expérimenter

Un **Lab** est une activité de recherche et d’expérimentation.

Un Lab est utilisé lorsqu’une recherche technique est utile pour réaliser le travail du Sprint.

Vous pouvez rechercher une information dans :

* Internet ;
* la documentation ;
* des exemples ;
* des ressources techniques.

Vous ne cherchez pas seulement une réponse.

Vous devez aussi **tester la solution**.

La démarche est :

**Chercher → Comprendre → Tester → Choisir**

Par exemple, vous avez besoin d’une solution technique que le tutoriel n’explique pas.

Vous recherchez plusieurs solutions.

Vous testez celle qui semble adaptée.

Vous gardez la solution qui répond au besoin.

Un Lab n’est pas nécessaire dans toutes les Sessions.

### Impact sur l’apprentissage

Le Lab développe une capacité essentielle pour un développeur :

**savoir chercher une solution lorsqu’on ne connaît pas encore la réponse.**

Vous devenez progressivement plus autonome.

Vous apprenez également à ne pas utiliser une solution sans la comprendre ou la tester.

## 3. Prototype — S’entraîner avant le projet

Le **Prototype** est une petite réalisation réalisée avant une réalisation plus importante du Projet Fil Rouge.

Son objectif est de vous permettre de **mettre en pratique vos acquis dans un nouveau contexte**, sans avoir immédiatement la difficulté d’un grand projet.

Par exemple :

**Tutoriel :** apprendre à réaliser une page.

**Prototype :** réaliser une **page détail d’un projet du Portfolio**.

Le contexte est différent du tutoriel, mais vous pouvez réutiliser les notions apprises.

### Pourquoi ne pas passer directement au Projet Fil Rouge ?

Une réalisation complète demande souvent plusieurs connaissances en même temps.

Si vous passez directement du tutoriel au projet, une difficulté peut venir de plusieurs causes :

* une notion mal comprise ;
* une mauvaise utilisation du code ;
* une difficulté à adapter la solution ;
* une difficulté à organiser la réalisation.

Le Prototype réduit cette difficulté.

Vous travaillez sur une **petite réalisation** avant de construire une réalisation plus grande.

### Ce que permet le Prototype

Le Prototype permet de vérifier :

**Ce que je sais faire.**

**Ce qui est encore difficile.**

**Ce que je dois corriger.**

Vous avez ainsi la possibilité de corriger vos difficultés avant d’entrer dans une réalisation plus importante.

### Exemple

Vous avez appris dans un tutoriel à réaliser une page.

Vous devez maintenant réaliser une page détail d’un projet.

Vous devez reprendre les connaissances du tutoriel et les adapter au nouveau contexte.

Vous ne copiez donc plus seulement un exemple.

Vous commencez à **réutiliser un acquis**.

### Live Coding du Prototype

Le Prototype peut également être présenté en Live Coding.

Vous réalisez une partie du travail devant le formateur.

Le formateur peut observer votre manière de réfléchir et de réaliser.

Il peut alors identifier une difficulté avant le Projet Fil Rouge.

### Impact sur l’apprentissage

Le Prototype joue le rôle d’un **entraînement entre le tutoriel et le projet**.

Il permet de passer progressivement de :

**Je reproduis**

à :

**Je sais utiliser ce que j’ai appris.**

C’est une étape importante pour développer l’autonomie.

## 4. Projet Fil Rouge — Construire progressivement

Le **Projet Fil Rouge** est construit pendant toute la formation.

Vous ne réalisez pas tout le projet en une seule fois.

Le projet avance par **Sprints**.

Chaque Sprint correspond à une étape de réalisation.

Par exemple :

**Page d’accueil → Page détail d’un article → Gestion des catégories → Gestion des articles**

Chaque Sprint apporte de nouveaux apprentissages.

### Réutiliser les acquis

Pour réaliser un Sprint, vous réutilisez les connaissances développées pendant :

**Tutoriels + Labs + Prototype**

Vous utilisez donc progressivement vos acquis dans une réalisation de plus en plus complète.

Par exemple :

**Tutoriel :** apprendre à réaliser une page.

**Prototype :** réaliser une page détail de projet.

**Projet Fil Rouge :** réaliser une page détail d’article.

Les trois réalisations utilisent des acquis proches, mais le contexte change.

Vous devez donc comprendre ce que vous faites et adapter votre solution.

### Impact sur l’apprentissage

Le Projet Fil Rouge vous apprend à :

**réutiliser → combiner → adapter → construire**

Vous développez progressivement la capacité à produire une réalisation complète.

Vous apprenez aussi à travailler sur un projet qui évolue dans le temps.

## 5. Présentation — Expliquer son travail

La présentation permet de montrer ce que vous avez appris et réalisé.

Vous devez pouvoir expliquer simplement :

**Ce que j’ai appris.**

**Ce que j’ai réalisé.**

**Comment je l’ai réalisé.**

Présenter votre travail vous oblige à organiser vos idées et à expliquer vos choix.

Vous développez ainsi une autre capacité importante du développeur :

**savoir expliquer son travail.**

## 6. Une Session forme une progression

Les étapes d’une Session ont chacune un rôle.

**Tutoriels** → construire les bases.

**Travail entre pairs** → s’aider et expliquer.

**Live Coding** → montrer et confirmer la compréhension.

**Labs** → rechercher et expérimenter.

**Prototype** → s’entraîner et adapter.

**Projet Fil Rouge** → réutiliser et construire.

**Présentation** → expliquer et partager.

Chaque étape prépare la suivante.

Vous ne passez donc pas directement de la théorie à une réalisation complète.

Vous avancez progressivement :

**Je découvre → Je comprends → Je reproduis → Je cherche → Je m’entraîne → J’adapte → Je construis → J’explique**

## 7. Travail à faire

Dans **Google Slides**, créez un schéma qui présente les étapes d’une Session :

**Tutoriels → Travail entre pairs → Live Coding → Labs si nécessaire → Prototype → Projet Fil Rouge → Présentation**

Pour chaque étape, ajoutez deux informations :

**Ce que je fais.**

**Ce que j’apprends.**

Ajoutez ensuite un exemple simple, par exemple :

**Tutoriel :** apprendre à réaliser une page.

**Prototype :** réaliser une page détail d’un projet.

**Projet Fil Rouge :** réaliser une page détail d’un article.

Présentez ensuite votre schéma devant les autres apprenants.

Pendant la présentation, expliquez comment chaque étape vous aide à progresser.

**Résultat attendu :** vous comprenez comment une Session organise votre apprentissage et vous savez expliquer comment passer progressivement de l’apprentissage d’une notion à sa réutilisation dans une réalisation complète.
