# Comment apprendre à Solicode ?

À Solicode, vous apprenez surtout **en faisant**.
Vous lisez, pratiquez, cherchez, réalisez et expliquez votre travail.

## 1. Tutoriels — Apprendre les bases

Les tutoriels vous permettent d’apprendre en **autoformation**.

**Lire → Comprendre → Reproduire → Tester**

Vous pouvez échanger avec les autres apprenants. Un **Live Coding** peut ensuite permettre à un apprenant d’expliquer sa réalisation. Le formateur confirme la compréhension et complète les connaissances.

## 2. Labs — Chercher et expérimenter

Lorsqu’un Lab est prévu, vous recherchez une solution dans **Internet, la documentation ou des exemples**.

**Chercher → Tester → Trouver une solution**

Le Lab développe votre autonomie technique.

## 3. Prototype — S’entraîner

Le Prototype est une **petite réalisation avant le projet complet**.

Exemple :

**Tutoriel** → apprendre à réaliser une page.
**Prototype** → réaliser une page détail d’un projet du Portfolio.

Le Prototype permet de **réutiliser les acquis, trouver les difficultés et corriger les erreurs** avant le Projet Fil Rouge.

## 4. Projet Fil Rouge — Construire

Le Projet Fil Rouge est réalisé progressivement.

Chaque étape correspond à un **Sprint** :

**Page d’accueil → Page détail d’un article → Gestion des catégories → Gestion des articles**

Vous réutilisez les acquis des tutoriels, Labs et Prototype pour construire une réalisation complète.

## 5. Présentation — Expliquer

Vous présentez votre travail :

**Ce que j’ai appris → Ce que j’ai réalisé → Comment je l’ai réalisé**

Présenter aide à mieux comprendre et à expliquer ses acquis.

## 6. À retenir

**Tutoriel** → apprendre.
**Lab** → chercher et expérimenter.
**Prototype** → s’entraîner et adapter.
**Projet Fil Rouge** → réutiliser et construire.
**Présentation** → expliquer et montrer.

La progression est :

**Apprendre → Pratiquer → Expliquer → Chercher → S’entraîner → Construire**

## 7. Travail à faire

Dans **Google Slides**, créez un schéma des étapes d’une Session :

**Tutoriels → Labs si nécessaire → Prototype → Projet Fil Rouge → Présentation**

Pour chaque étape, ajoutez **une phrase sur ce que vous faites et ce que vous apprenez**.

Présentez votre schéma devant les autres apprenants.

**Résultat attendu :** vous savez expliquer comment vous allez apprendre et travailler pendant une Session à Solicode.
