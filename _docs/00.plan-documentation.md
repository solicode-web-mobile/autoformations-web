# Plan de Documentation du Site Jekyll d'Autoformation

## 1. Vue d'Ensemble

Bienvenue dans la documentation technique et opérationnelle de la plateforme d'**Autoformations Web Solicode**.

Ce site statique est propulsé par **Jekyll** et le thème **Just the Docs**. Il permet de gérer le cursus d'apprentissage des apprenants à travers un système modulaire de **9 collections de contenu** interdépendantes.

Ce dossier regroupe tous les documents nécessaires pour :
- Comprendre le fonctionnement et la configuration du site Jekyll.
- Comprendre l'architecture et les relations entre les collections.
- Connaître la liste exhaustive des métadonnées (*Front Matter*) requises pour chaque collection.
- Apprendre à ajouter étape par étape une nouvelle entité (Session, UA, Domaine, Compétence, Mission, Tutoriel, Lab, Prototype, Sprint de projet).

## 3. Matrice des Rôles & Cas d'Usage

Identifiez votre besoin pour consulter directement le bon document :

### Cas 1 : Vous devez modifier l'apparence ou la configuration du site
Consultez [`01.configuration-site-jekyll.md`](01.configuration-site-jekyll.md) pour :
- Modifier les métadonnées globales du site dans `_config.yml`.
- Activer ou désactiver des fonctionnalités Just the Docs (recherche, bouton copie, navigation).
- Ajouter ou modifier des styles CSS dans `assets/css/` (interdiction stricte du CSS inline).
- Comprendre le chargement des scripts JavaScript ou la configuration de Mermaid.

### Cas 2 : Vous préparez une nouvelle session ou organisez le cursus
Consultez [`02.architecture-collections-jekyll.md`](02.architecture-collections-jekyll.md) pour :
- Comprendre comment s'articulent les 4 phases d'une session (*Apprendre $\rightarrow$ Explorer $\rightarrow$ Adapter $\rightarrow$ Transposer*).
- Visualiser comment les UAs se relient aux Domaines, Compétences et Missions.
- Identifier la structure requise pour relier les prototypes et les sprints fil rouge.

### Cas 3 : Vous devez créer un fichier et compléter ses métadonnées YAML
Consultez [`03.specifications-front-matter-collections.md`](03.specifications-front-matter-collections.md) pour :
- Obtenir la liste exacte des champs acceptés par le layout de votre collection.
- Savoir quels champs sont obligatoires et lesquels sont optionnels.
- Copier-coller un exemple de Front Matter valide et conforme.

### Cas 4 : Vous devez ajouter une Session, une UA, un Tutoriel ou une Activité
Consultez [`04.guides-creation-entites.md`](04.guides-creation-entites.md) pour :
- Suivre la procédure pas-à-pas d'ajout (nom de dossier, nom de fichier, liens Liquid).
- Renseigner correctement les codes de liaison (`code`, `ua`, `domaine`, `competence`, `session`).
- Exécuter la checklist de vérification avant de pousser vos modifications.

## 4. Règles Transversales de Contribution

Pour garantir la stabilité du site et la qualité pédagogique, appliquez rigoureusement les trois règles suivantes :

1. **Encodage strict :** Enregistrez tous vos fichiers (`.md`, `.html`, `.css`, `.js`, `.yml`) en **UTF-8 sans BOM**.
2. **Style rédactionnel direct :** Rédigez en français simple (A1–A2), avec des phrases courtes et des verbes d'action à l'impératif direct (*« Ouvrez »*, *« Créez »*, *« Testez »*). Bannissez le jargon complexe.
3. **Zéro CSS inline :** N'ajoutez jamais d'attribut `style="..."` ou de balise `<style>` dans les fichiers markdown ou layouts. Utilisez exclusivement les classes de `assets/css/`.
