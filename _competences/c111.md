# C.111 — Analyser un besoin existant

## Objectif

Exploiter un besoin logiciel déjà défini pour comprendre précisément le périmètre à réaliser avant sa conception technique.

## Compétence

Analyser un besoin logiciel fourni afin d’identifier :

- les acteurs ;
- les actions ;
- les fonctionnalités ;
- les comportements attendus ;
- le périmètre fonctionnel.

## Livrable attendu

Le résultat attendu est un **support fonctionnel analysé et annoté**.

Il doit faire apparaître :

- les acteurs ;
- les actions ;
- les fonctionnalités ;
- les comportements attendus ;
- le périmètre étudié ;
- les correspondances **acteur → action → fonctionnalité**.

## Transformation attendue

```text
Je dispose d’un besoin à comprendre
                ↓
Je comprends précisément
ce que le système doit permettre de faire
dans le périmètre défini
````

## Chaîne d’analyse

```text
Support fourni
      ↓
Acteurs
      ↓
Actions
      ↓
Fonctionnalités
      ↓
Comportements attendus
      ↓
Périmètre fonctionnel
```
