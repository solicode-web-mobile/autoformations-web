# S1 — Comprendre le projet et premiers traitements logiques

## Objectif

Découvrir le fonctionnement d’une application Web, comprendre le projet cible, identifier son contexte et ses acteurs, et construire les premiers traitements JavaScript dans le Sandbox Algorithmique.

## Description

L’apprenant découvre le projet cible avant toute réalisation technique.

Il analyse le contexte du **Blog personnel**, sa finalité, son périmètre et ses principaux acteurs.

Il découvre également le rôle des données dans une application et identifie les premières données nécessaires à son fonctionnement.

En parallèle, il construit un premier traitement JavaScript dans le **Sandbox Algorithmique**.

Les principaux outils utilisés pendant la formation sont également découverts à travers des Labs.

## Productions attendues

- Analyse du contexte et des acteurs du Blog personnel
- Liste initiale des données nécessaires au fonctionnement de l’application
- Petit programme JavaScript exécuté dans le Sandbox Algorithmique
- Productions des Labs de découverte
- Analyse initiale du Portfolio
- Petite transposition JavaScript exécutée en console

Les traitements portent sur des données simples liées au contexte du Blog personnel.

## Travail à réaliser

### Analyse du projet

- Observer la maquette générale du Blog personnel
- Identifier l’application, sa finalité générale, son domaine fonctionnel et son périmètre
- Identifier les acteurs principaux et leurs rôles
- Repérer les grandes parties et fonctionnalités visibles
- Identifier les premières données nécessaires au fonctionnement de l’application
- Relier les fonctionnalités observées aux données nécessaires
- Structurer les premières informations recueillies

### JavaScript

- Réaliser le programme prévu dans le Sandbox Algorithmique
- Manipuler des variables, des valeurs, des entrées simples, des calculs et des sorties console
- Réaliser une petite transposition JavaScript en console

Réaliser une première analyse du contexte du Portfolio.
